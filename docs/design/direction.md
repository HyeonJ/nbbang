# 엔빵 디자인 방향 — 스위스 그리드

2026-09-11 확정 (방향 2라운드: 1차 A장부/B영수증/C핀테크 기각 — 레트로 모노·핀테크 클리셰 배제, 2차 D매거진/E스위스/F서첩 중 **E 채택**). 시안: [prototypes/2026-09-11-directions-r2.html](prototypes/2026-09-11-directions-r2.html) §E.

## 컨셉

국제주의 타이포그래피 — 철도 시간표의 정확함. **돈은 정보고, 정보는 정확하게.**
장식이 아니라 구조(괘선·그리드·정렬)가 화면을 만든다. 유행을 타지 않는 클래식.

## 토큰

| 토큰 | 값 | 용도 |
|---|---|---|
| `--ink` | `#0a0a0a` | 텍스트·괘선·버튼 바탕 |
| `--accent` | `#ff4d00` | 인터내셔널 오렌지 — 포인트 **단 하나** (수입 금액·활성 태그·강조) |
| `--muted` | `#666666` | 보조 텍스트·라벨 |
| `--bg` | `#ffffff` | 지면 |
| `--hairline` | `#d8d8d8` | 보조 괘선 (1px) |

## 타이포

- **Archivo** — 숫자·라벨·태그. 금액은 항상 `font-variant-numeric: tabular-nums`, 볼드
- **Noto Sans KR** — 본문 400/500, 제목 900
- 금액 단위(원)는 본문보다 작게, 숫자가 주인공

## 형태 규칙

- 주 괘선 **2px 블랙**, 보조 괘선 1px `--hairline` — 카드가 아니라 표
- **radius 0, 그림자 0** — 입체감 금지, 위계는 굵기·크기·괘선으로
- 포인트 컬러는 화면당 한 계열만 (오렌지가 두 가지 의미로 쓰이지 않게)
- 버튼: 블랙 바탕 + 화이트 볼드, 보조 버튼은 2px 아웃라인
- 모바일 퍼스트 — 표는 컬럼 수를 줄이지 말고 가로 스크롤 대신 행 재구성

## 적용 시점

- Plan 01의 화면(로그인·목록·설정)은 기능 최소 UI로 두고, **Plan 02 직전 화면 디자인 라운드**에서 이 토큰으로 전 화면 시안 확정 후 일괄 적용
- Tailwind v4 `@theme` 토큰으로 위 값을 등록하는 작업은 화면 디자인 라운드의 첫 태스크
